# SME Sentiment & Response Architect 

## 1. Project Objective
This is a functional AI-powered tool designed for Small and Medium Enterprises (SMEs) in Almaty, Kazakhstan. It automates customer feedback loops by analyzing reviews and generating professional, culturally nuanced responses in both **Kazakh** and **Russian**.

The project follows the **IT4IT Framework**, demonstrating the transition from a junior programmer to a **Product Architect**.

## 2. Key Features
- **Sentiment Analysis:** Identifies customer mood (Positive, Negative, Neutral).
- **Automated Categorization:** Classifies reviews into Food, Service, Atmosphere, or Price.
- **Bilingual Generation:** High-quality replies in Kazakh and Russian to suit the local market.
- **Dynamic Model Selection (D2C):** The tool automatically detects available Gemini models (Flash/Pro) to ensure system stability.

## 3. Technology Stack
- **Language:** Python 3.11+
- **Frontend/UI:** Streamlit
- **AI Engine:** Google Gemini API (via `google-generativeai`)
- **Framework:** IT4IT Value Streams (S2P, R2D, R2F, D2C)
